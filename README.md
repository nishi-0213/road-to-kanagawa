# Road to Kanagawa

JavaScript / Phaser 3 / Cloudflare Workers / Durable Objects による PC ブラウザ向け協力ゲームの Step 1 プロトタイプ。

仕様は [現行仕様書](docs/GAME_DESIGN.md)、[原案](docs/ORIGINAL_PROPOSAL.md)、[変更履歴](docs/CHANGELOG.md) にまとめています。

## ローカル開発

Node.js 22 以降と npm を使用します。

```sh
npm ci
npm run build
npm run server
```

別ターミナルで `npm run dev` を起動し、Vite のローカルアドレスをブラウザで開きます。Vite は `/api` と WebSocket をポート8787の Wrangler に中継します。Wrangler だけでもビルド済みクライアントをポート8787で配信します。ローカルの Durable Objects は Cloudflare の認証不要です。

## 遊び方

- 名前を入力し「1人で遊ぶ」または「協力ルームを作成」を選択。
- **1人プレイは HTTP のルーム作成と WebSocket 接続を行いません。** シミュレーションはブラウザ内で、描画フレームごとの経過時間に合わせて動きます。
- 協力プレイでは作成者が12文字のコードまたは招待URLを共有し、他の人が入力して参加。招待URLを開いた場合はコードが自動入力されます。
- 最大4人。ホストが開始し、WASDまたは矢印キーで移動。Shiftを押しながら移動すると速度1.4倍で最大4秒走れます。走行中以外は6秒でスタミナが0%から100%へ回復します。使い切った後はShiftを一度離してから再走行できます。生存プレイヤー全員（現在は全参加者）が金色の脱出地点に2秒間とどまると、プログレスバーが満タンになって遷移します。誰かが地点を出ると進捗はリセットされます。
- 尼崎で脱出 → ホストが新大阪を指定 → 設計画面 → 全員が「準備完了」 → 新大阪で脱出 → クリア。
- 最後の人が準備完了するまでは解除できます。戦闘・クラフトは未実装です。

「ルーム作成」は共有サーバー上にゲームルームを作る操作です。ブラウザから他の人のPCでサーバープロセスを起動する仕組みではありません。友人とのプレイには、同じサーバーのURLにアクセスしてください。

## 通信と切断

1ルーム1 Durable Object。20Hzでサーバーが入力から座標を計算し、クライアントに状態を配信します。クライアント指定座標は採用しません。移動は正規化し、画面内に制限します。300ms入力が途絶えると移動を停止します。他プレイヤー表示は補間します。

開始後の途中参加・再接続・途中セーブは未対応です。切断した参加者は判定対象から除外し、ホスト切断時は次の参加者へ移譲します。全員退出するとルーム状態を初期化します。実行インスタンスの再起動では進行状態を失います。接続コードは認証用パスワードではなく、知っている人がロビーへ参加できる招待コードです。

## Cloudflare への公開

```sh
npm run build
npx wrangler deploy
```

Cloudflare アカウント認証と Workers / Durable Objects を利用できる設定が必要です。この実装は Workers Static Assets でフロントも同一オリジン配信します。Pages を分離する構成より通信経路を単純化しています。企画書の Pages 分離公開は今後対応できます。公開コマンドは自動実行しません。

PNG はまだ使わず Phaser の図形で仮表示します。PC キーボードを前提にしておりスマートフォン操作には対応しません。

タイトル、入力欄、ロビー、HUD、ルート、設計、結果、通知はすべてPhaserのゲームウィンドウ内に描画します。名前やコード入力では日本語IME・貼り付け用に非表示のネイティブ入力を併用します。ノードをホバーすると必要物資と特徴をゲーム内に表示します。物資の数値は未確定のため「未設定（現在は消費なし）」として表示し、資源消費は実装していません。

各ステージには2〜4個のチェストがランダム配置されます。近くでEを0.5秒長押しすると、食料2〜4・燃料2〜4・小銃1・ナイフ1・帽子1のいずれかをチームで共有取得します。開封進捗はチェスト上に表示されます。マップ表示と移動範囲は16×10タイル（1024×640）で統一しています。「タイトルへ」ボタンはありません。1人プレイのやり直しはページの再読み込み、協力ルームの退出は「退出」を使用します。
