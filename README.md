# Multiplayer Game

公開URL：https://road-to-kanagawa.fow-shogi.workers.dev

GitHub：https://github.com/nishi-0213/road-to-kanagawa

Cloudflare Workers + Durable Objects + WebSocket + Phaser の最小構成です。

ブラウザいっぱいの空のPhaserウィンドウに、HTMLの「1人で遊ぶ」「ルーム作成」「ルームコードを入力して入室」を重ねます。入室後はHTMLを隠します。入室すると「準備フェーズ」を表示し、右側に人数分の準備完了ボタンを並べます。自分のボタンのみ操作でき、全員が準備完了になると「戦闘フェーズ」へ移行します。戦闘ではWASDで移動し、Shiftで1.5倍のダッシュ（4秒消費・6秒回復）ができます。32pxタイルのランダムマップを左下から進み、右上の発光する脱出ゾーンへ全員が3秒集まると準備へ戻ります。ルームは最大4人で、ゲーム画面内にコードと人数、招待URLコピーを表示します。退出ボタンはありません。準備完了は全員が押すまで取り消せます。戦闘開始後の途中参加はできません。アカウント認証ではなく入室操作のみです。

## ローカル開発（Node.js 22以降）

```sh
npm ci
npm run build
npm run server
```

http://localhost:8787 を開きます。別ターミナルで `npm run dev` を起動すると http://localhost:5173 でクライアント変更を自動反映できます。

## 検証・公開

```sh
npm test
npm run build
npm run deploy:check
# サーバー起動中
npm run test:ws
npm run test:battle:ws
# Cloudflare認証後に公開
npm run deploy
```

WebSocket専用トークンは不要。APIトークンはデプロイ環境のみに設定し、GitHubやブラウザには含めないでください。1人プレイは通信しません。協力プレイは休止対応のDurable Objects WebSocket APIを使用し、ルーム存在フラグのみ永続保存します。ルームコードは招待用で、個別ユーザー認証や進行保存はありません。

プレイヤーはユーザー提供の透過32×32 PNG（`client/assets/player.png`）を使用します。

戦闘ごとに森林地帯・幹線道路・市街地区をランダム選択します。森林には提供された `tree.png` を密度の偏りのある障害物として配置し、全地形に岩も配置し、脱出までの通路を3本確保します。マップの外側は背景へフェードします。

箱の近くでEキーを1秒長押しすると、食料1〜4・燃料1〜4・ナイフ1・ライフル1のいずれかを獲得します。戦闘中は左上に自分の所持品をアイコン・名前・数で表示し、次の戦闘へ引き継ぎます。ゲーム終了後の保存やアイテムの使用は未対応です。協力プレイの同時開封は1人だけが取得します。

準備画面上部に尼崎から神奈川ゴールまでの13都市を表示します。脱出後は右側へ接続された次の都市をクリックして選び、全員準備完了で次の戦闘へ進みます。接続にはランダムな分岐・合流があり、1回の脱出につき1回進めます。箱は各戦闘3〜5個です。

都市ノードにマウスを重ねると特性と消費資源を表示します。通常70%、敵増加・資源増加・トレーダー各10%で、富士はイベント固定です。燃料は1〜3、食料は人数分を表示します。資源の実消費と特性のゲーム効果は今後の実装です。

箱の開封中は箱の上に小さな進捗バーを表示し、Eを離したり箱から離れるとリセットします。ルートは隣の都市だけをつなぎ、ショートカットなしで全都市を通ります。敵増加・資源増加・トレーダーは二重丸、イベントは三重丸です。
