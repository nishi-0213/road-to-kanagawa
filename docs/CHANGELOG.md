# 仕様・開発履歴

## 2026-10-23 — 現行仕様1.1

会話で確定した仕様を統合し、原案を変更せず保存。以後は仕様変更と同じコミットで現行仕様と本履歴を更新する。

### これまでの変更

- JavaScript / Phaser / Workers / Durable Objectsによる初期実装。1人プレイではWebSocketを使わない。
- タイトル、ルームコード・招待URL、最大4人ロビー、ホスト開始、サーバー権威の移動同期。
- 尼崎の脱出→新大阪選択→全員準備完了→新大阪で脱出してクリア。
- 64pxタイルの平原・道路、脱出時の緑オーラ。
- 1人プレイのフレーム単位更新と、全員が2秒滞在する脱出プログレス。
- 脱出ラベルを「脱出地点」に固定、進捗バーをオーラ上のゲーム内表示へ移動。
- 地名をノード上に表示するゲーム内ルートマップ、マウスオーバーで必要物資と特徴を表示。
- 表示UIをすべてCanvas内へ移行。Shiftで1.4倍・4秒走行、6秒で全回復するスタミナ。

### 今回の変更

- 各ステージに2〜4個のチェストをランダム配置。
- 食料2〜4、燃料2〜4、小銃1、ナイフ1、帽子1から1種類を抽選。
- Eを0.5秒長押しで開封、チェスト上の小さなプログレス、チーム共有取得と二重取得防止。
- 「タイトルへ」ボタンを削除。協力プレイの退出は維持。
- 表示タイルと移動範囲を1024×640に統一し、マップ全域をCanvas内へ収める。
- 原案・現行仕様・本履歴・今後の仕様更新ルールをリポジトリへ追加。

検証：単体テスト11件成功、Viteビルド成功。4つの実WebSocket接続でチェスト同時開封・二重取得防止・未開封内容の非配信・2ステージ進行を確認。ブラウザで2〜4個の表示、0.5秒開封バー、取得後表示、マップ四隅の描画、次ステージでの再配置、1人プレイのWebSocket接続0件を確認。
